# JETPiNG

**Android networking client — JETPiNG edition**

A rebranding and adaptation workspace based on [WhiteAestherMobile](https://github.com/WhiteDNS/WhiteAestherMobile), upstream tag `v1.17.0`.

## Project status

This repository has been created for the JETPiNG adaptation. The complete Android application source has **not yet been imported**; this first commit records the project identity and licensing requirements only. No APK is available from this repository yet.
